# Attestations recorded by onetaskgraph v0.14.14

Written by the released `onetaskgraph 0.14.14` binary, unedited, into a folder of Markdown
configured as source `notes`: project `launch`, task `a`, and task `b` depending on `a`, each
task attested `plan-review` by `review-plan` against bar `bar-1`. `attestations.rs` puts them
back under `projects/` and `tasks/` and holds that every later release reads both records
`valid`: an edge whose far end was never copied keeps the digest it had.
